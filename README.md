# EcoTravel Adventures

Author: Julian Acosta

Purpose:
EcoTravel Adventures is a fictional website promoting sustainable travel and eco-friendly tourism. It demonstrates semantic HTML, responsive CSS, media integration, and forms.

Structure:
- 10 HTML pages (index, about, destinations, destination-detail, things-to-do, events, gallery, blog, resources, booking, contact)
- css/styles.css
- images/ (placeholders)
- media/ (placeholders)

This project is designed for deployment on GitHub Pages.
